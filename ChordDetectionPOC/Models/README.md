# Core ML models

| File | What | Source | Licence |
|---|---|---|---|
| `BTCChords.mlpackage` | BTC chord recogniser, large vocabulary (170 classes) | [jayg996/BTC-ISMIR19](https://github.com/jayg996/BTC-ISMIR19), Park et al., ISMIR 2019 | MIT (`BTC-LICENSE.txt`) |
| `BTCKernels.bin` | Constant-Q filter bank for BTC's input features | generated by `Tools/btc/convert_btc.py` | same as above |
| `BasicPitch.mlpackage` | Polyphonic note transcription | [spotify/basic-pitch](https://github.com/spotify/basic-pitch) `icassp_2022/nmp.mlpackage`, unchanged | Apache 2.0 (`BasicPitch-LICENSE.txt`) |

Xcode compiles the `.mlpackage` files into the app automatically (this folder is part of the
synchronized group). The `chord-eval` command-line tool loads them from this folder with
`--models ChordDetectionPOC/Models`.

## Regenerating or fine-tuning BTC

How the model works, its training data and fine-tuning on your own songs: `Tools/btc/README.md`.

```sh
git clone https://github.com/jayg996/BTC-ISMIR19.git
pip install torch coremltools librosa pyyaml numpy
cd Tools/btc && python convert_btc.py --btc ../../BTC-ISMIR19 --out ../../ChordDetectionPOC/Models
```

The script rewrites BTC's forward pass with fixed shapes (checked against the original to 1e-5),
bakes the feature normalisation into the model and exports the CQT kernels the Swift code uses.

Note: the BTC weights were trained by its authors on research datasets (Isophonics, Robbie
Williams, UsPop2002).
The code and weights are released under MIT; if you ship the app commercially, it's worth
reading the upstream repository and paper for any dataset terms you care about.
